# FairHire AI — Research Experiments Directory

Stores experiment configurations, execution scripts, and recorded results.

## Structure
- `configs/`: Declarative experiment configurations (e.g., scoring weights, model names, dataset version references).
- `scripts/`: Benchmark runners and evaluation calculation scripts.
- `results/`: Machine-readable outputs (JSON/CSV) generated by experimental runs.

## Research Governance
- Every experiment run generates a unique experiment ID, timestamp, and parameter record.
- Results must record actual metrics (Precision, Recall, F1, Accuracy, Latency, Spearman $\rho$). No synthetic mock metrics are permitted.
